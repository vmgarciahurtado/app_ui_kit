# Sistema de Diseño Reutilizable en Flutter

## Objetivo
Construir un sistema de diseño reutilizable para Flutter y documentarlo visualmente mediante una app showcase.

## Qué aprenderá
* Design tokens
* Theming
* Componentes reutilizables
* Consistencia visual
* Separación entre estilos y pantallas
* Documentación visual de componentes

## Producto final
Un paquete llamado "app_ui_kit" con un showcase funcional.

### Qué debe hacer el producto
Debe incluir:
* Colores del sistema
* Tipografías
* Espaciados
* Botones
* Text fields
* Cards
* Chips
* Loaders
* Banners o mensajes vacíos
* Componentes visuales reutilizables

Y un showcase donde se vea cada componente funcionando.

## Qué debe hacer el dev
* Definir lineamientos visuales básicos.
* Crear archivo o capa de tokens.
* Definir colores, espaciados, radios y estilos de texto.
* Crear componentes base reutilizables.
* Evitar hacer widgets amarrados a una sola pantalla.
* Construir una app showcase, esta app es un example del paquete o externo al paquete, de ningún modo debe el paquete poder ejecutarse desde el paquete en sí.
* Organizar el showcase por categorías.
* Permitir ver variantes de cada componente.
* Documentar cómo se usa el sistema.
* SE RECOMIENDA USAR ATOMIC DESIGN.

## Herramientas
* Flutter package
* Sin paquetes externos innecesarios
* google_fonts opcional
